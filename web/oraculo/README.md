# Oráculo SOC web attack observations

Sanitized defensive observations are grouped by technique.

Supported technique identifiers:

- sql-injection
- xss
- ssrf
- ssti
- command-injection
- directory-traversal
- jwt-abuse
- graphql-injection
- nosql-injection
- file-upload
- request-smuggling
- xxe-xml-injection

Evidence published here must be bounded, sanitized or hashed. Raw credentials,
cookies, authorization material and internal infrastructure details are not
publication material.
