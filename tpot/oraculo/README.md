# Oráculo SOC T-Pot observations

Defensive artifact intelligence derived from historical T-Pot telemetry.

Canonical SHA256 records live under:

`sha256/<first-two-hex>/<sha256>/`

A record may be `metadata_only` when the original bytes are unavailable.

No file is published as a sample unless its bytes are independently available,
verified against the recorded SHA256, and explicitly safe for this public
repository.

Historical MD5-only identities are kept separately and are never promoted to
SHA256 artifacts without a trusted hash crosswalk.
