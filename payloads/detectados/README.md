# Payloads detectados

Listado visible de payload artifacts high-signal detectados por T-Pot y publicados por Oraculo SOC.

Total publicado: **517**.

Cada carpeta corresponde a una firma/SHA256. Al entrar, se ve la evidencia disponible: comandos defangueados, IOCs, metadata y detecciones si existían.

## Qué significa detectado

No todos son binarios malware completos. Muchos son payloads HTTP, comandos de explotación, downloaders, staging en `/tmp`, `wget`, `curl`, `busybox`, `chmod`, `sh` e infraestructura asociada.

El valor está en la señal defensiva observable.
