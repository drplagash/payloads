# Case Studies

Human-readable examples of T-Pot payload triage and malware analysis.

This folder is the portfolio layer: each case study should explain what was observed, why it mattered, what evidence exists, what indicators were extracted, and what detection value came from the artifact.

## Current case studies

```text
tpot-mips-payload-cad9e90/
```

## Case study format

Each case study should answer:

```text
What was observed?
Where did it come from?
Why was it classified as useful?
What indicators were extracted?
What behavior or technique does it suggest?
What detection logic can be built from it?
What remains uncertain?
```

The goal is to show analyst judgment, not just store files.
